# 2027 산림자원 기출회독 PWA v1.9.0

## 배포
이 폴더 전체를 HTTPS 정적 호스팅에 올리면 설치 가능한 PWA가 됩니다. GitHub Pages, Render 등 정적 호스팅을 사용할 수 있습니다.

## 업데이트
새 버전을 배포할 때 index.html과 sw.js의 CACHE_NAME 버전을 함께 변경합니다. 설치된 앱은 다음 실행에서 새 서비스 워커를 감지하고 상단에 `새 버전이 있어요` 배너를 표시합니다. `업데이트`를 누르면 새 버전으로 전환됩니다.

## 학습기록
같은 웹 주소(origin)를 유지하는 한 localStorage의 오답·북마크·답안·설정은 앱 업데이트 뒤에도 유지됩니다. 기존 로컬 HTML(file://)에서 웹 PWA로 처음 옮길 때의 기록은 자동 이전되지 않습니다.

## 오프라인
앱 본체는 한 번 로드한 뒤 오프라인에서도 열립니다. CBTBank 원격 시각자료는 한 번 표시되어 캐시에 들어간 이미지에 한해 오프라인에서 재사용될 수 있습니다.
